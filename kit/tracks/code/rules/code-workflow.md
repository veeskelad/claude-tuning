# Работа с кодом (направление code)

| Что нужно | Где искать |
|---|---|
| Баг или неожиданное поведение | скилл `systematic-debugging` — причина до фикса |
| Замечания ревью | скилл `review-triage` — разбор классами, а не точечно |
| Ревью перед отправкой | скилл `review-domain-checks` — классы багов, которые проходят CI и падают в проде |
| Важное решение по архитектуре | скилл `adr` |

- Новая задача в репозитории — `git fetch origin main`, затем worktree от `origin/main`. Смержил — сразу
  `worktree-cleanup`. Эталон читать из `git show origin/main:<путь>`: локальный main отстаёт.
- В отставшем клоне `git status` врёт по смыслу: он сравнивает с локальным `main`, и уже смерженная чужая правка
  выглядит как незакоммиченная работа. Прежде чем назвать что-то незакоммиченным — `fetch` и сверка с `origin/main`.
