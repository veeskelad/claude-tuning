# Гигиена файлов

Агент за пару недель обрастает мусором: дампы, черновики, скрипты на один запуск, копии конфигов «на всякий случай».
Правило — куда что класть и что убирается само.

## Куда класть файлы

| Тип файла | Куда | Не сюда |
|---|---|---|
| Разовый или временный артефакт текущей сессии (дампы, скрипты одноразового запуска, промежуточные данные) | scratchpad-папка сессии, если система её назвала; иначе временная папка, созданная под задачу (`mktemp -d`) | домашняя папка, чужие проекты |
| Результат работы над темой (отчёт, анализ, экспорт) | `~/projects/<имя>/`; без темы — `~/projects/_misc/<ГГГГ-ММ-ДД>-<тема>/` | корень домашней папки |
| Файл, относящийся к существующему проекту | внутрь этого проекта | соседняя папка «на всякий случай» |

Новый файл прямо в домашней папке отклоняет хук `home-clutter.sh`. Существующие файлы там (`.zshrc`, `.gitconfig`) править можно.

## Бэкапы конфигов

Ручная копия перед рискованной правкой — одна на файл: сначала `ls X.bak-*`; есть моложе 7 дней — новую не делать.
Нужна история версий — git, а не россыпь `.bak-*` рядом с оригиналом. Копия живёт, пока не подтверждено,
что правка стабильна (до 7 дней), потом удаляется.

Установщик набора делает так же: бэкап `settings.json.bak-ГГГГММДД` создаётся, только если моложе 7 дней другого нет.

## Автоуборка `~/.claude`

Руками такое не чистят — это делает скрипт `~/.claude/bin/claude-junk-clean.sh` по расписанию (раз в день, шаблон
launchd — `kit/launchd/claude-junk-clean.plist.template`; на Linux — cron). Он убирает:

- `*.bak*` в `~/.claude`, `rules/`, `hooks/`, `bin/` старше 7 дней;
- планы старше 14 дней — в `plans/archive/`, архив старше 90 дней — удаляет;
- пустые `session-env/` и временные `projects/-private-*`;
- историю правок `file-history` старше 30 дней;
- обломки установки плагинов.

Транскрипты сессий Claude Code чистит сам (настройка `cleanupPeriodDays`) — скрипт их не трогает.
Сначала пробный запуск: `claude-junk-clean.sh --dry-run` — печатает, что убрал бы, ничего не удаляя. Журнал —
`~/.local/state/claude-junk-clean/clean.log`. Появился новый вид мусора — дописать его в скрипт, а не чистить руками каждый раз.

## Периодический аудит

Раз в 1–2 месяца или когда тает место: найти крупные папки (`du -sh ~/* ~/Library/Caches/* 2>/dev/null | sort -h | tail`),
показать человеку список и удалять только с его «да».
