# Инструменты

## Тестовые контейнеры и приложения

- Контейнер для проверки — с меткой сессии: `docker run -d --label claude.agent.session=<id сессии> …`. Без метки страж
  отклонит запуск в фоне и подставит метку в текст отказа. Свой контейнер убирать одной простой командой
  `docker rm -f <имя>` (или `stop`, `kill`) без кавычек, цепочек и `$(…)`: страж сверит метку через `docker inspect` и
  пропустит. Так же на удалённом хосте: `ssh <хост> docker rm -f <имя>`. Чужой контейнер и контейнер без метки удаляет
  человек.
- Приложение: до запуска проверить, не открыто ли оно уже (на macOS — `osascript -e 'application "X" is running'`).
  Не было открыто — после проверки закрыть. Открытое до тебя не закрывать.

## Скиллы

- В списке скиллов сессии нет подходящего — `/find-skills <задача>` до начала работы.
- В шапке своего скилла указывать модель по сложности: рутина — дешёвая, код и анализ — средняя, архитектура и
  отладка — сильная.
