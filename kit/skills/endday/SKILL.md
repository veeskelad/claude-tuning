# Endday — завершение дня

`~/.claude/global-handoff.md` — одна точка правды для всех сессий и агентов. Файл накапливает записи, а не перезаписывается.

## 1. Собрать контекст

```bash
cat ~/.claude/global-handoff.md 2>/dev/null
bash ~/.claude/hooks/open-tasks.sh --all
git diff --stat "HEAD@{midnight}" 2>/dev/null; git log --oneline -5
```

Невыполненные обещания и блокеры из вчерашней записи — перенести.

## 2. Спросить человека (одним сообщением)

Что важного сделал сегодня · что на завтра · блокеры или обещания · есть ли урок, который стоит запомнить.

## 3. Записать handoff

Под секцией `### <проект>` новая запись **сверху**. Хвостовые разделы («Человеческий контекст») перезаписываются — они про сегодня.

🔑 Заголовок записи начинается с `- **Сессия ГГГГ-ММ-ДД` — иначе тиринг её не свернёт.

```markdown
## По проектам
### <проект>
- **Сессия <ГГГГ-ММ-ДД> — <что произошло и чем кончилось>**
  - <решения, статус, что осталось>
  - Чек-лист: <путь> — открыто N из M, следующий: <пункт>

## Человеческий контекст
- Сделано: …
- На завтра: …
- Блокеры и обещания: …
```

## 4. Свернуть остывшее

Утро читает файл целиком, поэтому он не должен расти: в реальной настройке за неделю он дорос до 74 КБ, около 18 700 токенов каждое утро.

```bash
~/.claude/bin/handoff-tier.py            # dry-run
~/.claude/bin/handoff-tier.py --apply
```

До 3 дней — полный текст; до 14 — заголовок со ссылкой `[детали]`; старше — в `~/.claude/handoff-workspace/ГГГГ-ММ/ГГГГ-ММ-ДД.md`. Ничего не удаляется. Второй прогон `--apply` обязан дать «0% меньше» — иначе скрипт задвоил записи.

## 5. Уроки

Урок, назвал человек — дописать в `~/.claude/projects/<slug>/memory/lessons-learned.md` (без дублей; файл читают только грепом).

## 6. Ревизия раз в неделю

Верхняя запись `~/.claude/tuning-log.md` старше 7 дней (или файла нет) — скилл `self-tune`: найти, о чём человек
просил снова и снова, и переписать инструкции и скиллы под него. Правки — в итог дня одной строкой каждая.
