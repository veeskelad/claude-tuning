# Morning — утренний дайджест

## 1. Вчерашний handoff

```bash
cat ~/.claude/global-handoff.md 2>/dev/null || echo "Нет сохранённого handoff. Начинаем новый день."
```

Записи старше 3 дней свёрнуты до заголовка со ссылкой `[детали]`, тело — в `~/.claude/handoff-workspace/ГГГГ-ММ/ГГГГ-ММ-ДД.md`. Архив целиком не читать: нужна старая деталь — грепом по теме:

```bash
grep -rniE 'ключевые|слова' ~/.claude/handoff-workspace/
```

## 2. Открытые задачи

```bash
bash ~/.claude/hooks/open-tasks.sh --all
```

Залежавшиеся (больше 7 дней) назвать отдельно: доделать или закрыть с причиной.

## 3. Кто ещё работает

Открытые сессии видны через `/list-agents` (Claude Code 2.1.224+). Живую сессию проще спросить напрямую (`@имя` и вопрос), чем читать её запись. Запись в handoff нужна для закрытых.

## 4. Git-статус

```bash
git fetch --quiet 2>/dev/null; git log --oneline -5
gh pr list --state open 2>/dev/null
```

`git status` в отставшем клоне врёт по смыслу: смерженное чужое выглядит незакоммиченным. Эталон — `git show origin/main:<путь>`.

## 5. Дайджест

```
## Вчера
<секции «По проектам» и «Человеческий контекст» из handoff>

## Сейчас открыты
<живые сессии из /list-agents, если есть>

## Открыто
<чек-листы: цель, N из M, следующий пункт>

## Сегодня в git
<коммиты, открытые PR>
```

Затем одним вопросом: «Что делаем сегодня?» — с предложением первым взять следующий пункт самого свежего чек-листа.
