# Session Handoff — завершение работы в проекте

**Сводка сессии пишется сама** (скилл `claude-session-bridge`): хуки SessionEnd и PreCompact
запускают `auto_summary.py`. Он берёт выжимку транскрипта, пишет сводку моделью с потолком бюджета и
кладёт её в `~/.agents/handoffs`. Оттуда её читают Codex, вечерняя сборка `global-handoff.md` и
утренняя сводка. Пропускаются короткие сессии без правок и `claude -p`. Своя ручная сводка
(`handoff.py save`), свежее транскрипта, не перетирается.

Открытой соседней сессии handoff не нужен: её спрашивают напрямую (`/list-agents`, `@имя`, Claude
Code 2.1.224+). Закрытую возвращают `claude --resume <имя или id>`; найти по теме — `session-search`.
Безымянную сессию трудно найти: дать имя по задаче — `/rename <задача>`.

## По запросу

1. **Сводка сейчас** (не ждать закрытия):
   ```bash
   python3 ~/.agents/skills/claude-session-bridge/scripts/auto_summary.py run --agent claude \
     --session <id из SessionStart> --transcript ~/.claude/projects/<slug>/<id>.jsonl --cwd "$PWD" --force
   ```
   Следующий шаг известен лучше, чем видно из транскрипта, — ручная сводка `handoff.py save`
   (формат и команда — в скилле `claude-session-bridge`).
2. **Чек-лист** `.tasks/<slug>.md`: отметить сделанное по факту; доделанную задачу закрыть.
3. **Проектные доки.** `git diff --name-only` от начала сессии: поменялось поведение, команда запуска
   или структура — обновить README, CLAUDE.md проекта или `docs/`. Поведение не менялось — не трогать.
4. **Память проекта** (`~/.claude/projects/<slug>/memory/`): факт, который не выводится из кода и git
   и понадобится через месяц, — один файл на факт и строка в `MEMORY.md`. Сессия изменила описанное —
   поправить запись сразу: память, которая врёт, хуже отсутствующей.
5. **Worktree и мусор.** Скилл `worktree-cleanup` (если стоит): `scan`, затем `clean` для смерженных.
   Временные файлы сессии — в scratchpad, в проекте не оставлять: `*.tmp`, `*.bak`, `*~`, `*.swp`.
6. **Коммит** — только если человек попросил. Без подписей о генерации.

Скилла `claude-session-bridge` нет — запись в `~/.claude/global-handoff.md` руками под `### <проект>`,
новая сверху, заголовок начинается с `- **Сессия ГГГГ-ММ-ДД — …**` (формат — в скилле `endday`).

## Отчёт

Что обновлено (доки, память, чек-лист), что убрано, id сводки из
`~/.local/state/claude-tuning/auto-summary.log`, что ждёт человека — 4–6 строк. Пустой результат тоже
назвать: «дерево чистое», «память не устарела».
