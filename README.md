# claude-tuning

Набор, который за один разговор настраивает Claude Code под человека: Claude помнит, на чём вы остановились, не может случайно удалить важное или показать пароли, реже спрашивает «можно?» и со временем сам подстраивается под ваши привычки.

*English: a Claude Code kit that sets up memory between sessions, safety guards against destructive commands and secret leaks, fewer permission prompts and self-tuning instructions — installed through a short interview. Docs are in Russian.*

## Как поставить

Скопируйте в Claude Code текст из [`INSTALL-VIA-AGENT.txt`](INSTALL-VIA-AGENT.txt). Claude скачает набор, задаст 5–6 коротких вопросов (чем вы занимаетесь, как вам отвечать, что ему можно делать без вопроса), покажет простыми словами, что поставит, и ничего не поменяет без вашего «да». В конце — таблица «было → стало» и как всё вернуть.

Нужны: Claude Code, `bash`, `python3`, `jq`, `git`. Проверено на macOS; на Linux работает без задач по расписанию через launchd (подсказывается строка для cron); Windows без WSL — нет.

## Направления: что ставить

Основа ставится всем. Остальное человек выбирает при знакомстве — по тому, чем занимается.

| Направление | Для кого | Что получает человек | Флаг установщика |
|---|---|---|---|
| **Основа** | все | Claude помнит работу между чатами, не удаляет важное и не показывает пароли, реже спрашивает разрешения на безопасное, сам убирает за собой, переносит длинный разговор в новый чат | — |
| **Программирование** | пишет код, смотрит ревью | каждая задача в своей копии проекта, поиск причины ошибки до исправления, разбор замечаний к коду, без отправки кода в обход проверок | `--with code` |
| **Серверы** | работает с серверами | Claude не сделает изменение, после которого пропадёт доступ к серверу, и сверяет ключи между машинами, не показывая их | `--with servers` |
| **Тексты и ролики** | контент, видео | проверка и «очеловечивание» русского текста, расшифровка речи, Word и Excel, безопасные зоны для вертикальных роликов | `--with content` |
| **Codex** | работает и в Codex | Codex соблюдает те же запреты, что Claude, видит те же скиллы и сводки сессий; задачу можно передать между ними на полуслове | `--with codex` |
| **Задачи по расписанию** | хочет, чтобы что-то делалось само | Claude выполняет повторяющиеся задачи без человека: с лимитом денег, коротким списком разрешённого и одной кнопкой «стоп»; расписание включает только человек | `--with autonomy` |

## Что и чем сделано — по сферам

| Сфера | Простыми словами | Из чего состоит | Направление |
|---|---|---|---|
| **Память** | Claude помнит, на чём остановились, даже в новом чате и на следующий день | чек-лист задачи `.tasks/<slug>.md` и правило `tasks-policy.md`; хуки `open-tasks.sh` (открытые задачи на старте) и `compact-context.py` (возврат задачи после сжатия); `session-autosave.sh` (запись о каждой закрытой сессии); скилл `claude-session-bridge` — при закрытии сессии и перед сжатием модель пишет короткую сводку «что сделано, что дальше» в `~/.agents/handoffs` (до $0,25 из лимита подписки за сводку, короткие сессии пропускаются, выключить: `CLAUDE_TUNING_AUTO_SUMMARY=0`), в 23:30 сводки дня собираются в `global-handoff.md`, в 07:00 — утренняя сводка, которую показывает первая сессия дня; скиллы `session-handoff`, `endday`, `morning`, `session-search`, `memory-consolidate`; `handoff-tier.py` (старые записи сжимаются) | основа |
| **Перенос длинного разговора** | разговор слишком длинный — Claude предложит продолжить в новом чате без потерь | мод `handoff`: на 60 % контекста сессия пишет документ передачи, очищает контекст и продолжает с раздела «Сейчас» | основа |
| **Защита от удаления** | нельзя одной командой стереть домашнюю папку, базу или незакоммиченную работу | хук-страж `safety-guard.sh`: блок необратимого, вопрос на рискованное, проверка скриптов, которые удаляют файлы; `home-clutter.sh` (не мусорить в домашней папке) | основа |
| **Защита паролей и ключей** | Claude не покажет пароли и ключи в чате и не впишет их в файл | `secret-guard-bash.py` и `secret-mask.py` (подменяют вывод на имена и метки), `guard-secret-read.sh`, `guard-secret-in-output.sh` (тревога, если значение прошло); `secret-value.py` — сверка и перенос ключей по хешу, без значения; `scan-transcripts-for-secrets.sh` | основа |
| **Меньше вопросов «можно?»** | на безопасные действия Claude не спрашивает разрешения | dippy (ставится отдельно, `brew tap ldayton/dippy && brew install dippy`) через `dippy-script.py` и белый список `~/.dippy/config`; адаптеры режимов `bypass-ask-to-deny.sh`, `unless-bypass.sh`, `plan-auto-allow.sh`; проверка плана отдельным агентом перед показом | основа |
| **Правила работы** | Claude знает, что делать сам, а что только после «да», и не ходит по кругу | шаблон `CLAUDE.md`-карты; правила `~/.claude/rules/`: `autonomy.md` (уровни L0–L3 и «копия → изменение → проверка → откат»), `file-hygiene.md`, личный `autonomy-areas.md` по ответу при знакомстве; `loop-detector.sh`; приёмка по результату — «готово» только после проверки | основа |
| **Подстройка под человека** | повторённые просьбы и поправки Claude со временем превращает в правила | скилл `self-tune` и `repeat-scan.py` (повторы, напоминания «продолжай», ручной перенос данных, поправки, уроки, записанные второй раз); хук `correction-nudge.py` — на «опять», «я же просил», «запомни» Claude записывает правило в том же ходе; раз в неделю утренняя сводка показывает найденные повторы и зовёт `/self-tune`; раздел «Подстройка» в панели диалогов (`tuning-suggest.py`): что пора улучшить и что давно не делалось — ревизия, память, повторный урок, лишние скиллы — с кнопками «сделать», «обсудить», «позже», «не предлагать»; ответы пишутся в `~/.claude/tuning-feedback.jsonl`, и по ним совет больше не повторяется или меняется; каждая правка — с копией и журналом `~/.claude/tuning-log.md` | основа |
| **Видно, что происходит** | под полем ввода — контекст и лимиты, над ним — какие ещё чаты работают и ждут ответа | `statusline.sh`; мод `session-hub` (в приложении Claude и в терминале; в VS Code — панель сбоку); стиль ответов «Простой» | основа |
| **Порядок** | раз в день Claude убирает свои временные файлы | `claude-junk-clean.sh` по расписанию; вечерняя и утренняя сборка сводок (launchd на macOS; на Linux установщик печатает строку для cron) | основа |
| **Обновления** | вышла новая версия набора — Claude скажет и обновит по «да» | `tuning-update-check.sh` раз в сутки; «обнови набор» (SKILL.md, «Обновление набора»); `~/.claude/claude-tuning.json` — что и какой версии стоит | основа |
| **Код** | задачи не мешают друг другу, ошибки чинятся по причине | скиллы `worktree-cleanup`, `systematic-debugging`, `review-triage`, `review-domain-checks`, `adr`; хуки `repo-freshness.sh` (каждые 30 минут), `agents-md-drift.sh`, `guard-hard-rules.py` (без `--no-verify`, ветки от свежего `origin`, без правок основной копии); правило `code-workflow.md` | программирование |
| **Серверы** | не оборвать себе доступ, замер до обхода | правило `ops-safety.md` | серверы |
| **Тексты и ролики** | безопасные зоны 9:16, вычитка, расшифровка | правило `vertical-video.md`; сторонние скиллы их установщиками (`vendor.json`) | тексты и ролики |
| **Codex** | Codex не удалит важное и продолжит задачу Claude | мост `claude-parity`: хуки Claude запускаются в Codex (`pre_tool_guard.py`, `claude_bridge.py`, `skill_inventory.py`) — дописываются в конец `~/.codex/hooks.json`, чужие не двигаются; `~/.codex/AGENTS.md`, если своего нет; `unify-agent-files.sh` (один файл правил на оба агента). После установки — в Codex `/hooks` и доверить новые хуки | Codex |
| **Автономия** | задачи сами по расписанию, безопасно | `claude-run.sh` (пауза → блокировка → дешёвая проверка входа → `claude -p` с бюджетом и узким списком инструментов → проверка «готово» → запись прогона); `claude-autonomy pause|resume|status|new|schedule`; страж `autonomy-pause-guard.sh`; правило `autonomy-runs.md`; скилл `autonomy-check` (программа проб) | задачи по расписанию |

## Обновление

Раз в сутки при старте сессии набор проверяет, не вышла ли новая версия, и пишет одну строку. Скажите «обнови набор»: Claude подтянет новую версию, перескажет, что изменилось, покажет, что поменяется у вас, и поставит только по «да» — с теми же направлениями, что стояли. Моды обновляются вместе с набором. Выключить проверку: `CLAUDE_TUNING_UPDATE_CHECK=0`.

## Установка вручную

```bash
K=~/.claude/skills/claude-tuning
python3 $K/scripts/install-kit.py                          # что будет сделано, ничего не меняет
python3 $K/scripts/install-kit.py --with code,servers       # то же с направлениями
python3 $K/scripts/install-kit.py --with code --apply       # поставить
python3 $K/scripts/install-kit.py --with code --check       # проверить
```

## Что установщик меняет и чего не трогает

- Скиллы — в `~/.agents/skills/` со ссылками из `~/.claude/skills/` (и `~/.codex/skills/`, если есть Codex); хуки — в `~/.claude/hooks/`, правила — в `~/.claude/rules/`.
- В `~/.claude/settings.json` добавляет только недостающее: хуки, `env`, строку статуса, моды. Перед правкой — копия `settings.json.bak-ГГГГММДД`. Подпись ИИ в коммитах остаётся; убрать — ответом при знакомстве.
- **Ничего не перезаписывает.** Файл с тем же именем и другим содержимым остаётся и попадает в отчёт «своя версия».
- `CLAUDE.md` создаёт, только если его нет. Существующий переписывается вместе с вами, а не копией поверх.
- Не читает и не выводит значения ключей. Ничего не запускает по расписанию, кроме ежедневной уборки (и проверки свежести копий проектов с направлением «программирование»).

## Удаление

```bash
python3 ~/.claude/skills/claude-tuning/scripts/install-kit.py --with <те же направления> --uninstall           # что будет снято
python3 ~/.claude/skills/claude-tuning/scripts/install-kit.py --with <те же направления> --uninstall --apply
```

Снимаются только файлы, совпадающие с набором, и только его хуки. Ваши правки, чужие хуки, `env`, `CLAUDE.md`, handoff и чек-листы остаются. Полный откат настроек — копия `~/.claude/settings.json.bak-ГГГГММДД`.

## Своё поверх набора

Личное (свои серверы, пути, хуки, скиллы) держите отдельной папкой той же формы и подключайте поверх, а не правкой набора:

```text
my-claude/
  skills/<имя>/SKILL.md
  hooks/<скрипт>
  bin/<скрипт>
  rules/<правило>.md
  settings.snippet.json     # {"hooks": {...}, "env": {...}} — как в kit/settings.snippet.json
```

```bash
python3 ~/.claude/skills/claude-tuning/scripts/install-kit.py --extra ~/my-claude --apply
```

## Настройка

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `CLAUDE_WORK_ROOTS` | папки с проектами для `open-tasks.sh --all` и `repo-freshness.sh`, через двоеточие | `~/Work:~/Projects:~/code` |
| `CLAUDE_SECRET_READ_ALLOW` | файлы с ключами, которые агенту можно читать, через двоеточие | пусто |
| `CLAUDE_FRESHNESS_OFF` | `1` — не делать `git fetch` на старте сессии | выключено |
| `CLAUDE_TUNING_UPDATE_CHECK` | `0` — не проверять новые версии набора | включено |
| `CLAUDE_GUARD_NO_AI_SIGNATURE` | `1` — страж не пропустит подпись ИИ, вписанную в текст руками (направление «программирование») | выключено |
