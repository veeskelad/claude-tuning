# Установка и обновление

Один установщик на оба случая: `scripts/install-kit.py`. Сам понимает, что происходит, по файлу `~/.claude/claude-tuning.json` (что стоит, какой версии, сумма каждого поставленного файла).

| | Первая установка | Обновление |
|---|---|---|
| Как запустить | вставить `INSTALL-VIA-AGENT.txt` в Claude Code | сказать Claude «обнови набор» |
| Что первая строка прогона | `Первая установка` | `Обновление 3.6.0 → 3.7.0` |
| Знакомство и вопросы | да, 5–6 коротких вопросов | нет, направления берутся из прошлой установки |
| Что ставит | всё выбранное | обновляет то, что стоит и не правилось; новое предлагает отдельно |
| Ваши правки файлов | — | остаются, в отчёте «своя версия» |
| Откат | `settings.json.bak-ДАТА`, `--uninstall` | то же |

## Первая установка

1. Вставьте в Claude Code текст из `INSTALL-VIA-AGENT.txt`.
2. Ответьте на вопросы, посмотрите сухой прогон, скажите «да».
3. Установщик запишет `~/.claude/claude-tuning.json` с версией, направлениями и суммами файлов.

## Обновление

Раз в сутки при старте сессии хук `tuning-update-check.sh` сверяет версию с тегами `vX.Y.Z` на GitHub и пишет одну строку, если вышла новая.

**Вручную (по умолчанию).** Скажите «обнови набор». Claude подтянет набор (`git pull --ff-only`), перескажет CHANGELOG между вашей версией и новой, покажет сухой прогон и поставит по «да».

**Файл не правили, он просто устарел** — обновляется сам (в отчёте «обновлено»). **Правили вы** — остаётся как есть («своя версия», рядом команда `diff`). Узнаём по сумме из `claude-tuning.json`; у установки старше 3.8 карты сумм ещё нет, тогда файл сверяется с историей git набора: совпал с одной из прежних версий — не правка, обновляем.

**Автоматически (по желанию).** Включить: `python3 ~/.claude/skills/claude-tuning/scripts/install-kit.py --auto-update on` (выключить: `off`; либо переменная `CLAUDE_TUNING_AUTO_UPDATE=1`). Хук сам подтянет новую версию и обновит только то, что уже стоит и не правилось. **Не делает без вашего «да»:** новые хуки и их запись в `settings.json`, новые задачи по расписанию, новые файлы, Codex, строка статуса. Если такое появилось, хук скажет об этом одной строкой. Если в клоне набора свои правки и `pull` не проходит, хук ничего не меняет и сообщает об этом.

**Моды.** Старая установка, у которой путь к модам указывал в другое место (копия в `~/.claude/mods`), при обновлении переводится на текущий клон. Моды заработают в новом чате.

## Для автора: выпустить версию

1. Пишете изменения в `CHANGELOG.md` под «Не выпущено», простыми словами.
2. `scripts/release.sh 3.8.0`: переносит запись под номер и дату, пишет `VERSION`, прогоняет `tests/update-flow.test.sh`, коммитит, ставит тег `v3.8.0`.
3. `git push origin HEAD v3.8.0`. Пока тег не отправлен, у людей «новой версии» нет.
